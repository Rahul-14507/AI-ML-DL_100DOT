# Daily log

Copy one block per day to the top of `my-progress/daily-log.md`.

```
## Day N - YYYY-MM-DD

Topic:
Time spent (minutes):
Task done: yes / partly / no

What I did:

What was unclear:

Tomorrow:
```

Example:

```
## Day 4 - 2026-11-03

Topic: Python lists, tuples, sets, dictionaries
Time spent (minutes): 70
Task done: yes

What I did:
Finished exercises 1 to 6. Wrote a word counter using a dict.

What was unclear:
When to use a tuple instead of a list. Will ask in the group.

Tomorrow:
Loops and conditionals. Start with FizzBuzz.
```

Keep it short. Two or three honest lines are better than a polished paragraph.
